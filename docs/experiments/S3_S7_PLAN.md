# 后续扩展边界

当前阶段交付S0–S2基线。根据架构§0.3和§16.1，在S2真实基线建立前不叠加A–G。`extensions`的任何非disabled配置均明确拒绝；没有用枚举冒充实现。

后续依赖顺序：A空间场/分离衰减散射 → B深度标定/适配 → C路由与null回退 → D1高频残差和D2相位 → E求解器/蒸馏/潜空间各独立路线 → F DG/UDA/TTA → G任务适配和第二后端验证。

每条路线须实现架构文件指定的数学目标、数据契约、训练/推理、checkpoint表示检查、关闭/缺失处理、消融和验收，然后才能命名为完成。真实深度、任务标注或教师权重缺失时，实验保持条件不足。当前没有这些路线的有效实验数字。
