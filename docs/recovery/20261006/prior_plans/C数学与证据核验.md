# C 方向：把“门控热图”收敛为可验证的新增先验效用选择

日期：2026-10-04。本文是下一轮框架的独立技术建议，未修改增强仓库源码，未启动训练。

## 1. 结论与优先级

**C 可以列入三个值得继续的候选，但不能说它已经进入实测效果最好的前三名。** 现有 C_ROUTED 对 C_FIXED 的验证集差异约为 +0.005954 dB，UIEB 和 LSUI 测试差异分别为 -0.001613 / -0.001325 dB，尚无稳定收益。选择 C 的理由是能够构造清晰且成本有限的机制检验，而不是已有质量证据强。

下一轮 C 的最小主张建议限定为：

> 对同一个冻结的条件扩散父模型，在同一个已经冻结的真实交叉注意力增量模块组中，能否仅根据退化图像和可用先验，选择“不开启 / 开物理 / 开颜色 / 开高频 / 全开启”，使质量优于验证集选定的最佳固定模式，同时降低新增先验导致的损害？

这是“新增条件分支的整图效用选择”，不是“全模型拒绝错误先验”，也不是“逐位置、逐时间步的因果路由”。这一范围能够保留父模型，无需先做一次从零开始的替代主干训练。

若要保留原设计的“全部物理/颜色/高频条件都能被拒绝”的强主张，必须另建 `C_CLOSED` 实验身份，真正移除父主干的旧先验绕行通路。它不能悄悄混入本轮小预算方案。

## 3. 先修正“测试了什么”的身份问题

### 3.1 现有模块为什么不是交叉注意力

现有 C 使用同一位置的 query 和 prior encoding 点积，再经过 sigmoid：

\[
Z(p)=V(E(P)(p))\,\sigma\!\left(\frac{Q(H)(p)^\top E(P)(p)}{\sqrt C}\right).
\]

其中 \(p\) 表示一个图像位置，\(H\) 是主干特征，\(P\) 是先验，\(Q,E,V\) 是学习变换。它没有让位置 \(p\) 检索其他位置或其他色度 bin，因此是逐位置门控，不是原架构要求的跨 token 注意力。

### 3.2 null 必须在代数上严格为零

现有 `self.out(result)` 带可训练 bias。即使门控使 `result=0`，也可能输出 `bias`。只在全部先验缺失时乘零，不能保证“有先验可用但选择 null”时零更新。

新结构应先完成每个分支的投影，最后再加权：

\[
\Delta H=\sum_{k=1}^3 w_k Z_k,\qquad Z_{\varnothing}\equiv0.
\]

在求和之后禁止再接带偏置的共享层、激活或归一化。硬选择 null 时直接返回未改动的 \(H\)。输出投影优先 `bias=False`；即便分支内存在偏置，末端硬选择 null 仍应严格零残差。

### 3.3 父模型有三条旧先验绕行

现有父模型首先拼接 \([x_t,I,J_p,\mathrm{resize}(hist)]\)，并在浅层加上高频特征。只关新增 C 模块，这些旧路径仍在。故：

- 本轮 `C_ADDITIVE_BANK` 的 null 恢复“原父模型”，不恢复“完全不看先验的图像增强器”。
- `adapter_only_corruption` 只污染新增分支，回答新增模块能否拒绝坏输入。
- `all_path_corruption` 连旧路径一起污染，回答整个当前系统有多脆弱；此时 null 没有质量保证。
- 两种污染必须分表报告，禁止用前者声称后者的鲁棒性。

## 4. 推荐的五模式冻结模块组

“模块组”（bank）指三种真实先验 cross-attention 模块及五种可执行开关方式；不是额外训练五个完整扩散模型。

固定模式集合为：

\[
\mathcal M=\{\varnothing,\mathrm{phy},\mathrm{color},\mathrm{freq},\mathrm{all}\}.
\]

每幅图只在采样开始前选择一次模式，整个 DDIM20 轨迹均使用该模式。DDIM 是确定性或可控制随机性的扩散快速采样方式；本轮沿用已审计的 `eta=0` 和样本键绑定噪声，不临时改变采样器。

硬选择是只执行一个离散模式，避免把“整图最终收益”错误地贴成“每位置、每时间步收益”。

### 4.1 冻结范围

冻结父模型去噪器、原先验产生器和原高频网络：参数 `requires_grad=False`，冻结部分保持 `eval()`。新增 encoder / attention / output projection 可以训练。

**冻结参数不等于对整个父网络前向使用 `no_grad()`。** 更新插在父网络中间的增量模块时，梯度还需要穿过后续冻结层回到增量模块。只禁止父参数更新，不切断这条梯度链。

验收记录所有父张量训练前后 SHA256；不能只检查优化器参数列表。整体 `model.train()` 会递归切换冻结父 dropout 状态，需要显式防止。

### 4.2 先验 token 的可实现定义

token 是用于注意力计算的向量条目。物理和频率 token 对应空间区域；颜色直方图 token 对应色度 bin，不对应图像坐标。

三类 token 的特征维度设为 128，每类最多 256 个，作为一个预先声明的实现选择，不宣称该维度理论最优。

物理 token 输入沿用父模型实际字段：

\[
P_{phy}=\operatorname{concat}(J_p^{(3)},d_{parent}^{(1)},
\kappa_D^{(3)},\kappa_B^{(3)},A^{(3)},t_D^{(3)},b^{(3)},v^{(1)}),
\]

合计 20 通道。关键约束：

- \(d_{parent}\) 必须是父字段计算实际使用的 `physical_coordinate`，不能用 `distance_proxy` 替换后却保留旧 \(t_D,b,J_p\)。这些字段必须来自同一次先验计算。
- 本轮保持原耦合系数 \(\kappa_D=\kappa_B=\kappa\)，不顺手引入 A 的系数解耦、linear RGB 迁移或新深度适配。
- 若父坐标实质上是历史归一化逆深度，只能称“历史物理代理特征”，不能说已修正成真实米制物理模型。
- \(v\) 是数值有效掩码或有效面积比例；没有校准数据时不能把它命名为可靠性概率。若额外提供经验分歧，另列实验而非直接伪装为 \(P(\mathrm{correct})\)。
- \(t_D=\exp(-\kappa_Dd_{parent})\)、\(b=A(1-\exp(-\kappa_Bd_{parent}))\) 与父 renderer 一致。这只验证实现一致，不证明父代理物理正确。

颜色使用原始 `PriorBundle.histogram`，保持其色度 bin 坐标，经 encoder 到 16×16 token；禁止把已放大到图像平面的 `condition['histogram']` 当作位置先验。高频使用同一父 Sobel/Haar 融合特征；本轮不掺入 D 的相位模块。

物理 / 高频 token 使用归一化图像坐标编码，颜色 token 使用色度 bin 编码。逐通道归一化若需要训练集均值方差，统计量只能来自训练集并冻结，验证和测试不能重新拟合。

### 4.3 真正的多头交叉注意力

在主干 1/4 与 1/8 分辨率分别注入；主干该层特征展平为 \(H_l\in\mathbb R^{B\times L_l\times C_l}\)。4 个头，每头 32 维：

\[
Q_{lh}=\operatorname{LN}(H_l)W^Q_{lh},\qquad
K_{lkh}=E_k(P_k)W^K_{lkh},\qquad
V_{lkh}=E_k(P_k)W^V_{lkh},
\]

\[
A_{lkh}=\operatorname{softmax}_{token}
\left(\frac{Q_{lh}K_{lkh}^{\top}}{\sqrt{32}}+M_k\right)V_{lkh},
\]

\[
Z_{lk}=\operatorname{concat}_{h=1}^4(A_{lkh})W^O_{lk}.
\]

\(B\) 是 batch 大小；\(L_l\) 是该层空间位置数；\(C_l\) 是通道数；LN 是逐 token 的层归一化；softmax 在可检索的先验 token 维度归一化。\(M_k\) 将无效 token 设为负无穷。

遇到某样本某分支全部 token 无效，先跳过注意力并直接产生零张量。禁止先做全负无穷 softmax，再试图用 `0 * NaN` 清理。对混合 batch 单独处理，不把一张图的缺失标志广播给整个 batch。

模式注入：

\[
\Delta H_l(m)=
\begin{cases}
0,&m=\varnothing,\\
Z_{lk},&m=k,\\
\frac13(Z_{l,phy}+Z_{l,color}+Z_{l,freq}),&m=all.
\end{cases}
\]

`all` 固定除以 3，无效分支置零；默认不按剩余分支重归一化，以免缺失导致其它支路增幅。若比较另一个归一化方式，必须有单独配置身份。

每个 \(W^O\) 零初始化，初始全部模式与父模型等价。首次反向内部 Q/K/V 可能梯度为零，输出投影应有梯度；完成一次非零投影更新后内部梯度应恢复。不能把初始零梯度当成“这个模块永远学不到”。

静态 token/K/V 可在一次推理中缓存；训练时参数变动后不能继续使用带旧梯度或旧权重的跨步缓存。复杂度约为 \(O(B\cdot4L_l\cdot256\cdot32)\)，不是满分辨率自注意力的 \(O((HW)^2)\)。

## 5. 两阶段训练，杜绝效用标签失效

### 阶段 C1：只训练模块组

每个训练 batch 在四个非空模式中等概率抽取一种，同一批次样本也可使用独立模式并明确实现。null 固定等于父模型，没有可学习参数，不必浪费 20% 的 batch 训练它。

模块组训练使用项目原像素 / 感知目标、相同增强和采样时间分布；不同时引入额外物理损失、相位损失或数据变化。默认只训练新增参数，父状态严格不变。

先做 100–200 步运行/梯度检查，再 1000 步诊断。若非空模式持续与父输出数值相同，先查梯度、学习率、token 样本配对；若因未收敛不能下方向无效结论。只有实现与梯度通过后，才考虑预定的 3000–5000 步小预算完成点。

**不得按已看过的测试成绩挑最好的步数。** bank checkpoint 只按训练内预定规则 / 开发验证集选择；冻结后生成哈希。

### 阶段 C2：模块组冻结后，生成训练效用标签

设 \(f_{\theta,\psi,m}(I_i;\xi_i)\) 是模式 \(m\) 的最终增强输出；\(\theta\) 是冻结父模型，\(\psi\) 是已经冻结的模块组参数，\(\xi_i\) 是同一图像共享的初始噪声。最终输出按照同一 padding、裁剪、颜色空间和指标实现计算：

\[
s_{im}=\operatorname{PSNR}(f_{\theta,\psi,m}(I_i;\xi_i),Y_i),\qquad
u_{im}=s_{im}-s_{i\varnothing}.
\]

PSNR（峰值信噪比）是以 dB 表示的图像参考误差指标，输入范围为 \([0,1]\) 时为 \(-10\log_{10}(\mathrm{MSE})\)；它与感知自然程度不是同一概念。

五个模式必须使用同一个样本键、初始噪声、分辨率和最后一幅输出。不允许用模式各自最好的随机噪声或不同采样步数。`u_null=0` 精确成立。

记录每条标签的 `sample_id, scene_id, split, parent_sha, bank_sha, prior_config_sha, sampler_sha, noise_key, metric_version`。一旦 bank 或上述任一条件变化，标签缓存失效，必须重算。

所有训练效用标签只由训练图像和其参考图生成。标签停止梯度；绝不把测试参考图、测试 PSNR、预测误差图或 corruption 严重度真标签送入选择器。

父模型可能已经在同一训练集学过，因此训练标签会有记忆偏差，但这不等于非法泄漏；需要在未见开发场景评估选择泛化。仅把路由头数据拆成两折，不能称“教师从未见过该图像的交叉拟合”，因为父权重仍见过全训练集。若要声称真正教师交叉拟合，需要从训练时即没有见过该折场景的父权重；本轮不默认支付这一成本。

### 阶段 C3：训练输入可见的效用预测器

选择器输入 \(z_i\) 只允许来自 \(I_i\)、父模型可计算的固定先验 token 统计和有效标志。建议用小型图像 encoder 的 64 维全局特征，结合三类 token 的均值 / 标准差摘要；优于仅用 7 个全局均值，但具体维度是可审计的实现选择，不宣称最优。

输出四个非空模式的效用预测，null 分数固定为零：

\[
\hat u_i=r_\phi(z_i),\quad \hat u_{i\varnothing}=0,\quad
\mathcal L_{utility}=\frac1{4N}\sum_i\sum_{m\ne\varnothing}
\left(\frac{\hat u_{im}-u_{im}}{a}\right)^2,
\]

其中正数 \(a\) 只由训练标签计算并冻结。正的统一尺度不改变 argmax。选择：

\[
\hat m_i=\arg\max_{m\in\mathcal M}\hat u_{im}.
\]

平局时按固定优先顺序选择 null，然后选择成本较低的模式；避免无意偏爱新增模块。

平方回归在无限数据和函数充分表达的理想条件下学习 \(\mathbb E[u_m\mid z]\)，因此按预测期望效用选模式，对这个有限硬选择集合的期望 PSNR 有清晰决策解释。这个推导不是有限数据性能保证。

Huber 回归可作为稳健替代，但一般不再严格估计条件均值；不能沿用上述最优性解释。直接用 oracle 赢家做交叉熵训练也容易忽略“赢 0.001 dB、输 0.5 dB”的幅度差异，故不是默认方法。

默认不引入效用 head 和 bank 联合训练；后者会使标签对应的动作结果变化。若后续联合优化，必须另开实验并重建标签一致性机制。

## 6. 真正可证明的 oracle 上界

oracle 指用参考图事后为每张图挑出这五个最终输出中最好的一个，它只能用于分析，不是可部署模型：

\[
m_i^*=\arg\max_m s_{im},\quad
S_{oracle}=\frac1N\sum_i\max_m s_{im}.
\]

对于同一冻结模块组、同一输入噪声和同一候选集合的任意硬选择器：

\[
S_{selector}\le S_{oracle},\qquad
R_i=\max_m s_{im}-s_{i\hat m_i}\ge0.
\]

\(R_i\) 是 regret（与有限候选中最佳决策相比损失了多少 dB）。该不等式可逐图检查。

最佳固定模式 \(m_{fixed}\) 只在开发验证集整体均值上选一次，再冻结到确认集。训练集最优固定模式可作为另一基线，但不能在每个测试集单独挑最好的固定模式后混称统一部署策略。

报告两种 oracle gap：相对验证选定的固定模式、以及相对当前评估集事后最佳固定均值。后者只是诊断，不用于部署选择。若连 \(S_{oracle}-\max_m\overline{s_m}\) 都很小，单靠选择这五个动作没有足够收益空间，应停止扩大路由器。

**边界：**这个 oracle 不上界新的权重、soft 输出融合、像素级混合、不同时间步模式切换或其它采样器。例如两个输出分别比目标高/低相同偏差，二者平均可以超过两者本身。因此任何 soft mixture 对照超越该 oracle 都不说明公式失效，而说明它不在同一硬动作类中。

若扩展评估噪声种子，先明确 oracle 是“每图每噪声选动作”还是“按每图跨噪声均值选动作”；前者额外看到噪声 realization，不能与仅有固定图像输入的选择器含混比较。

## 7. 公平对照的最小矩阵

| 对照 | 与学习硬选择器的关系 | 目的 |
|---|---|---|
| PARENT_FROZEN / null | 相同父权重；没有新增残差 | 检验新增模块是否真的提供净收益 |
| BANK_BEST_FIXED | 同一 frozen bank，固定使用验证选定模式 | 主要匹配控制，隔离“根据输入选择”的收益 |
| BANK_RANDOM | 同一 bank，以训练期固定概率和可复现随机数选模式 | 检验仅随机模式多样性是否足够 |
| BANK_CONST_GATE | 同一 bank，输入无关的可学习混合/固定策略 | 排除“所有图都偏爱某一路”的伪自适应；soft 版本单独标动作类 |
| C_ALL_ONLY | 同父、同新增架构、仅训练 all 模式 | 检验 bank 的混合模式训练是否引入不利/有利正则，而非选择本身 |
| C_CONV_CONTROL | 同父、近似参数匹配的图像特征残差卷积 | 区分 attention 先验信息与普通额外容量；若中心主张不涉及 attention 优越，可放第二阶段 |
| BANK_ORACLE | 每图看参考选择 | 只给有限动作上界，不算可部署方法 |

最少不能缺 PARENT、BANK_BEST_FIXED、输入选择器和 oracle。要把 attention 结构写成贡献，需要补等参数卷积；要把模式训练收益与选择收益拆开，需要 C_ALL_ONLY。

公平训练不仅比较 steps：all 模式运行三个注意力分支，单分支模式只运行一个，实际 FLOPs 不同。记录总可训练参数、每模式前向成本、累计 GPU 时间；同时展示同更新步数与等计算预算的边界，不能用相同 steps 自动宣称相同成本。

学习选择器训练也计入方法成本；离线五模式标签生成属于额外训练成本，不能省略。推理时只运行选择器一次和被选模式，不运行五个候选再做选择。

## 8. 低成本 go/no-go 决策

以下阈值是建议预注册的工程筛选规则，不是统计学定理或所有期刊的发表门槛；应在服务器实际运行前冻结。

### C0：实现和敏感性检查

- 确认 checkpoint 可读；记录输入 / 输出和指标基线；冻结父状态。
- 真 attention 形状正确，改变非同位置 token 能影响 query 输出；全无效 token 不产生 NaN。
- null 模式与同一次父前向数值一致；混合 batch 每图选择独立；所有模式零初始化与父输出一致。
- 投影非零更新后 Q/K/V 梯度非零；父参数和 dropout 状态保持冻结。
- 运行 24–48 个训练诊断场景，观察不同模式输出差；这些场景只用于调试，不用于最终统计结论。

### C1：有限候选有无可利用空间

完成预定短训并冻结 bank，在开发验证集计算全部五模式最终结果。

- clean oracle 对最佳固定模式的平均上限不足 +0.10 dB：默认不继续把“clean 平均 PSNR 提升”作为 C 的主路线；报告上限、区间和样本分布。
- clean 上限足够，但只由一两个图推动：先按场景 bootstrap 和损害率确认，不能直接扩大训练。
- 若目标预注册为错误先验鲁棒性，可另考察污染场景下的 oracle gap；不能看见 clean 失败之后悄悄更换主终点。污染鲁棒性必须伴随 clean 非劣约束，例如 clean 平均降幅不超过 0.05 dB。

### C2：能否从输入预测收益

- 在训练标签上训练小型预测器，验证使用最终硬模式输出，不能只看效用回归误差或 oracle 赢家准确率。
- 主比较 `selector - BANK_BEST_FIXED`；同时报告 `selector - PARENT`、regret、最差 10% 变化和损害比例（如每图低于固定控制超过 0.1 dB）。
- 若 oracle 明显有空间但输入选择器泛化失败，结论是“当前输入特征难以预测候选效用”，不是“注意力已经有效”。先诊断可预测性，不堆更多专家。
- 若选择器仅在训练 seen corruption 有优势，在未见类型无收益，不能声称普遍可靠性。

### C3：只有通过后才补三种子

对同一父模型，重新初始化 bank、路由器及训练顺序运行至少三个微调种子。这验证的是“给定这个父权重的适配稳定性”，不能写成从头独立训练稳定性。

若已有另外两个独立父模型的可用 checkpoint，可做不同父模型层面的复核；没有时不强迫立即从头花费三份 40 万步成本，也不得扩大结论范围。

场景分组 bootstrap 反映图像/场景采样不确定性；三种子结果反映有限的训练波动。每种子分别报告效果并列出均值/标准差，不把 3×N 张逐图结果混成独立样本扩大显著性。

## 9. 数据与标签隔离

现有 UIEB test、LSUI test 已被反复分析并影响下一轮设计，继续跑它们应称历史测试集上的探索性复核；不能再称全新盲测证据。

下一轮应建立并冻结一个场景独立的确认队列。候选可以来自父模型未用过的公开数据部分或许可明确的新数据，但要核验与 UIEB / LSUI / 先验模型预训练暴露的关系；不得仅重命名旧 test。

划分以场景 / 视频序列为单位，exact hash 之外需要近重复候选人工或明确流程复核。未知 scene_id 不能伪造。旧测试图的相近 crop 也不能进入新训练标签缓存。

数据角色至少为：`train_bank`、`train_selector`（可与前者同训练集合，明确有无独立子集）、`development`、`confirmation`。只有 train 生成用于参数学习的 reference utility；development 可用于预注册的选择/阈值；confirmation 在模型和协议冻结前禁止读取参考分数。

开发集可事后计算 oracle 以作 go/no-go，但这也是一次模型开发使用，须入账。最终确认集 oracle 只能在部署选择器已经冻结后作为描述性分析。

## 10. 可靠性与效用必须区别

可靠性通常指某个估计是否接近其目标，例如深度误差小不小；效用指把这个估计提供给指定增强器后，最终任务损失是否下降。一个深度估计可以更准确但对当前主干没有额外作用，一个粗糙先验也可能符合当前主干偏好。

本方案监督的是有限模式的最终增强效用，因而不需要把深度分歧校准成真实概率。仅当有合法独立深度标签或可靠目标时，才增加“先验可靠性校准”分支。

本方案也不使用逐先验 leave-one-out 值 \(\ell(Y_{-k})-\ell(Y_{all})\) 来直接给单路专家排序：先验间可能有交互，该差值是“其它先验都存在时的边际贡献”，不是“单独开启该先验的效用”。五模式实际最终输出的标签避免这项偷换。

## 11. 先例与创新界限

RPL-UIE 方法第 3.3–3.5 节已经把可靠教师先验、残差先验扩散和频率校准相连，式 (13)–(16) 将残差拆为低频与高频，并用空间通道门控调制高频；它说明“先验质量不同”“高频可能不可靠”“教师监督先验”本身不是新贡献。

CoRe-UIE 已有输入派生退化 cues、区域 Top-2 专家路由、共享基础专家、response alignment 和 HSIC 特征约束；它说明“按退化状态选择专家”“区域自适应融合”不是新贡献。其全文对模型结构的表述和某些实现细节仍有不充分之处，这不允许我们忽略其已经公开的方法主题。

当前候选真正需要证明的差异是：**在同一个冻结增强器与固定候选分支上，以可重放的最终任务收益训练选择器，明确区分可靠性与效用，允许严格新增分支回退，并公开输入选择器与有限 oracle 的差距。**

这仍然是待验证研究设计，不是本报告证明了原创性。若效果只有 +0.005 dB 或只能在人工污染上出现，通常不足以支撑强方法稿。若能在独立场景、多个适配种子和未见污染下获得稳定匹配收益、降低损害率，并能迁移到第二种增强主干，则才有更有说服力的论文方向。

新增 cross-attention 本身、参数量加大本身、固定父模型快训本身，以及 oracle 更好本身，都不能单独成为有效算法创新证据。

## 12. 本地数学核验与待服务器核验

已编写并运行 `scratch_c/math_probe_c.py`，采用 NumPy 对公式进行独立数值检查。9 项断言覆盖：跨 token 影响、全无效注意力精确零、显式 null 精确零、共享末端 bias 的反例、有限硬选择 regret 非负、oracle 高于最佳固定均值、选择器不超过 oracle、正尺度不改变 argmax、soft 输出融合不受 hard oracle 约束。

这不是 PyTorch 模型测试，不是训练结果。当前本地没有 checkpoint 和增强输出，尚未验证：实际梯度、初始父输出等价、显存、性能、三种子稳定性、外部测试收益、视觉质量。服务器任务必须逐一补齐，不得将数学 probe 的通过写成算法有效。

## 13. 给服务器 Codex 的 C 专项约束摘要

1. 先只做 C0 检查和估算，不重训父模型，不跑 A/F/G，不改变旧实验记录。
2. 实现真正的 token cross-attention 和严格 null；保留父 bypass 时在所有报告中使用 `additive` 身份。
3. 固定五模式；整图采样前选择，20 步不切换；一幅图的五模式使用相同噪声键。
4. 先训练 bank、冻结哈希，再生成 train-only 最终 PSNR 标签、训练输入选择器；禁止联合更新使标签失效。
5. 最强固定模式由开发集选择，最终确认集不重新选；oracle 明确只是离线分析。
6. `kappa_D=kappa_B`、历史深度坐标、未校准有效掩码必须如实命名，不偷偷引入新物理模型。
7. 主要匹配差异是选择器对同 bank 固定模式；另报父模型、all-only、卷积和随机控制，分清训练预算。
8. 先验证有 oracle 空间，再验证输入可预测性，最后才追加三个适配种子；任何阶段不通过都保留结果并停止升级。
9. 输出配置与权重哈希、逐图/逐场景指标、三种子表、误差/效用校准图、统一色标门控记录、损害案例、真实端到端耗时和受限结论。
