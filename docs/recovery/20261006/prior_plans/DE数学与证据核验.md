## 1. 决策结论

建议综合入围 **E、C、D**，其身份不同：E 是已有明确效率收益、应首先完成的无需训练诊断；C 是有条件推进的主要方法候选；D 是 C 未通过机制检查时的一次低预算备选。入围不等于三个已有效算法，也不应同时堆到一个网络里。

- E：已有 DDIM20 相对 DDPM1000 的约 41.5 倍“模型端到端”时延改善，是资源优化最直接的方向；它是既有采样算法的应用，尚不构成新算法。
- D：验证集 `D_PHASE − D_SOBEL_CONTROL = +0.008533 dB`，95% 图像 bootstrap 区间 `[+0.000393,+0.016228]`；UIEB test `+0.007652`，LSUI test `−0.001831`。这是小且不一致的探索信号，不能称稳定收益。多个方向筛选后的未校正区间也不能自动当作确认性显著性。
- C：应由主方案处理真实先验效用、输入干预、回退与匹配控制。E 为其节省评估预算；D 只提供一个表示层面的简洁替代假设，避免再次长时间撒网。

`+0.10 dB` 是本项目预先选择的实用收益门槛，不是“具有论文创新”的数学定义。E 应使用质量非劣与成本下降目标，不能强迫效率方法同时满足 `+0.10 dB`；C／D 若以重建质量为主张，才需要在匹配控制上达到预先冻结的实用门槛。统计稳定、方法新颖性和实验成本是三个不同维度。

## 2. 对前轮审计的两处必要澄清

### 2.1 D2 并不存在“未复刻 Phaseformer 就违反原设计”的问题

原 `CODE_RECONSTRUCTION_ARCHITECTURE.md:674` 起的 D2 明确规定：首版使用 `phase_spatial`，经卷积编码后接 C 频率分支或浅层残差；阈值为 float32 `1e-6`，低幅值置零。当前 `branches.py:21` 的实现与这一首版接口一致。

因此，本轮不能把 D_PHASE 的浅层卷积分支叫作 D2 的实现错误。真正的问题是：

1. D1“高频残差扩散”没有实施；D1 与 D2 是不同实验。
2. D2 没有证明相位相对 Sobel 的稳定增益。
3. 尚未控制输入表示尺度，尚未诊断低幅值相位的不稳定性与相位分支是否被使用。
4. 它不是 Phaseformer 的完整复现，不能复用 Phaseformer 的方法名称或论文数字。

拟议的 soft phase 是**新增研究变体**，不是修复此前违反设计的 bug。

### 2.2 E0 的“端到端”有明确边界

`run_e0.py:73` 开始计时 pad 与条件／先验生成；随后分别计时采样、裁剪与最终 clip，记录两段之和。每张图只计算一次先验，再将同一 `prior_seconds` 计入各采样器记录。

它包括：pad、深度／物理／颜色／频率先验生成、去噪网络调用、裁剪、最终 clip。

它排除：文件读取与解码、resize 前处理中的读图部分、CPU→GPU 传输、指标计算、PNG 保存、服务队列。没有明确 warm-up／重复试次策略。峰值显存在先验生成之后 reset，故不能作为完整先验加采样流程的真实峰值显存证据。

后续报告应称“模型端到端时延”；真正部署时延另测。DDIM20 的巨大加速现象仍有效，但不能把上述边界省略。

## 3. E 的数学基础及 20 步约等于 1000 步的解释边界

### 3.1 统一符号

- $Y$：配对参考图像，仅训练或评价可用。
- $I$：输入水下图像。
- $c(I)$：由输入构造的条件，不包含参考图像。
- $t\in\{1,\ldots,T\}$：数学时间；网络接收整数索引 $t-1$。
- $\beta_t$：每步噪声方差参数。
- $\bar\alpha_t=\prod_{j=1}^{t}(1-\beta_j)$，且 $\bar\alpha_0=1$。
- $a_t=\sqrt{\bar\alpha_t}$，$s_t=\sqrt{1-\bar\alpha_t}$。
- $f_\theta(x_t,t-1,c)$：当前代码直接预测的清晰图像，即 $x_0$ 预测器。
- NFE：去噪网络实际前向次数，必须通过调用计数测量。

前向加噪：

$$x_t=a_tY+s_t\epsilon,\qquad\epsilon\sim\mathcal N(0,I).$$

由 $x_0$ 预测得到噪声预测：

$$\hat\epsilon_t=\frac{x_t-a_t f_\theta(x_t,t-1,c)}{s_t}.$$

确定性 DDIM 从 $t$ 跳至 $u<t$：

$$x_u=a_u\hat Y_t+s_u\hat\epsilon_t,\qquad\hat Y_t=f_\theta(x_t,t-1,c).$$

当 $u=0$，$a_0=1,s_0=0$，因此直接返回 $\hat Y_t$。该公式与 DDIM 原文 Eq. (12)、Appendix C.1／D.3 的 $\eta=0$ 形式一致；原文用 $\alpha_t$ 表示本文的累计量 $\bar\alpha_t$，不可混成单步 $1-\beta_t$。

**现代码的确定性 DDIM 公式和 $t-1$ 索引映射在静态阅读下是自洽的。**尚无 checkpoint 级结果可判定整个训练模型是否按意图利用扩散状态。

### 3.2 一步与多步末端不同，必须单独测试

现 `time_grid` 是 `round(linspace(T,1,NFE))+[0]`。当 $T=1000$：

| NFE | 数学时间表 | 网络索引 |
|---|---|---|
| 1 | `[1000,0]` | `[999]` |
| 2 | `[1000,1,0]` | `[999,0]` |
| 4 | `[1000,667,334,1,0]` | `[999,666,333,0]` |
| 20 | 从 1000 经固定网格到 1，再到 0 | 最后一次为 0 |

DDIM20、DDIM100 与 DDPM1000 都在接近无噪声的 $t=1$ 调用一次预测器；DDIM1 直接在 $t=T$ 预测。故“20 与 1000 的指标接近”不意味着“一步可用”。

此外，平均 PSNR／SSIM 接近不意味着逐像素输出接近；必须同时计算原始输出的逐图 MSE、最大绝对差及 LPIPS。

### 3.3 强条件回归是待检验解释，不是已确诊退化

忽略感知项时，平方误差下最优 $x_0$ 预测器满足：

$$f^*(x_t,t,c)=\mathbb E[Y\mid x_t,t,c].$$

若假设条件后验 $Y\mid c\sim\mathcal N(m_c,\tau^2I)$，则：

$$f^*(x_t,t,c)=m_c+\frac{a_t\tau^2}{a_t^2\tau^2+s_t^2}(x_t-a_tm_c).$$

这给出一个可解释的简单例子：当条件很强、$\tau^2$ 很小且噪声较大时，输出主要由 $m_c$ 决定；不同噪声或轨迹可能给出近似相同的重建。在理想极限 $f_\theta(x_t,t,c)=g(c)$ 下，各采样器末次输出都等于 $g(c)$。

但真实训练还有感知项，上述高斯假设也不是已知事实；而在小 $s_t$ 区间，状态敏感性可能重新很强。不能由 E0 表格直接写出“扩散失效”“网络已退化为回归”或“扩散不是必要的”。

### 3.4 无需训练的诊断矩阵

只使用预先冻结的开发／验证场景。原 UIEB test 和 LSUI test 已用于上一轮分析，不能再作为新一轮从未见过的最终盲测。

| 诊断 | 固定项与改变项 | 要回答的问题 | 限制 |
|---|---|---|---|
| NFE 曲线 | 同一 checkpoint、同一 $x_T$、同一图像条件；NFE=1/2/4/8/20，DDPM1000 小规模复核 | 最低可用调用数 | 比较质量非劣，不能只看平均分 |
| 初始噪声敏感性 | 每图至少 3 个预定 evaluation noise seed | 是否输出几乎不依赖初始噪声 | 不是 3 个训练种子 |
| 中间预测轨迹 | 保存每次 $\hat Y_t$ 与最终图差值、逐时刻输出 RMS | 后续迭代修正了多少 | 轨迹图不自动证明因果必要性 |
| 时间输入干预 | 固定某个真实轨迹状态，换网络时间索引 | 网络是否利用时间嵌入 | 错配 t／噪声属于诊断分布，不能称合法采样器 |
| 状态输入干预 | 固定 $c,t$，替换零状态／匹配统计的噪声／其他图轨迹状态 | 网络是否利用 $x_t$ | 零状态和错配状态可能分布外，只能诊断 |
| 前向 oracle 诊断 | 用参考图构造 $q(x_t\mid Y)$，仅评价预测误差随 t 的变化 | 训练分布内去噪是否有效 | 使用了 GT，严禁当增强推理成绩 |
| 条件干预 | 同一轨迹、一次仅屏蔽一种合法条件接口 | 强条件依赖来自哪条路径 | 记录是否仍有旧先验旁路 |

推荐先对 `PARENT_85000` 与 `BASE_CONT_5000` 两个冻结权重做 24 张固定验证子集、3 个评估噪声种子；通过最低步数筛选后，只把 1 个候选和 DDIM20 推至全验证集。DDPM1000 重复成本高，可限在固定小子集；不得为了省时间省略 DDIM20 主对照。

质量主判据建议：候选相对 DDIM20 的逐图 PSNR 差均值 95% 单侧下界 $>-0.10$ dB、SSIM 单侧下界 $>-0.002$，且 LPIPS 差单侧上界低于事先冻结的感知容差。没有 LPIPS 不能称完整感知非劣；可先标记为工程候选。

多个 NFE 用同一开发集筛选会产生选择偏差：最终确认必须使用新的保留场景或外部未参与开发的数据，不能把挑出最好 NFE 后的同一验证区间当独立确认。至少报告最差场景群与预定尾部指标，不得只保留有利均值。

### 3.5 停止与升级条件

1. 若计数、时间索引、模型输出类型、clip 边界或 PNG／浮点评估不一致，停在实现修正，不增加训练。
2. 若 NFE=2/4 已达到质量非劣且总模型时延有效下降，冻结该配置为工程基线，优先把训练预算留给 C。
3. 若 NFE<20 未通过，不得硬上蒸馏；先确认是否存在部署时延需求，以及教师质量是否够强。默认维持 DDIM20。
4. 只有确有剩余成本瓶颈、教师有可靠质量且留有明确预算时，才另开蒸馏实验。一步 DDIM不等于一致性模型；减少 `steps` 不等于蒸馏。本文不把未经重新全文核验的 Consistency 超参数写入可执行首轮。

## 4. D 的数学基础：相位有结构信息，不是水下退化不变量

### 4.1 当前相位表示

对于一幅图的每个通道，令正交归一 FFT 为 $Z_k=\mathcal F(I)_k$，幅值 $A_k=|Z_k|$。当前单位相位：

$$P_k=\begin{cases}Z_k/A_k,&A_k>10^{-6},\\0,&\text{其他},\end{cases}
\qquad S_\phi=\Re\mathcal F^{-1}(P).$$

相位描述频率分量的位置关系。实图的频谱满足共轭对称；实值、共轭对称的幅值权重能维持逆变换为实图。丢掉数值舍入量级的虚部是允许的，任意非对称频率权重则不允许。

Phaseformer 的核心不同：对中间特征提取相位信息，再生成注意力的 query／key，value 保留原特征；另有相位引导的跳连。它提供相位表示的直接先例，不能证明当前浅层 D2 必然有效。其 UIEB 800/90 划分也与本项目 702/91/97 不同，不允许横向照抄论文 PSNR 比较。

### 4.2 低幅值不稳定性

将复数 $Z$ 写成二维向量 $z\in\mathbb R^2$。单位相位 $p(z)=z/\|z\|$ 的微分为：

$$Dp(z)=\frac{1}{\|z\|}\left(I-\frac{zz^\top}{\|z\|^2}\right).$$

沿相位方向的敏感度为 $1/\|z\|$，故幅值越小，同样的加性噪声造成的相位误差越大。相位角不应直接做普通差值，还存在 $-\pi/\pi$ 周期跳变。当前硬阈值避免除零，但没有消除阈值附近的不连续性。

单位幅值归一后，Parseval 能量守恒给出：若有 $K$ 个有效频率、共 $N=HW$ 个位置，则

$$\sum_x|S_\phi(x)|^2=K,\qquad\operatorname{RMS}(S_\phi)=\sqrt{K/N}.$$

通常 $K\approx N$，所以 RMS 约为 1；无论原图对比度大还是微弱噪声，单位相位都可能给出强特征。Sobel 梯度幅值一般随对比度缩放，直接比较二者可能混入输入尺度与有效学习率差别。

### 4.3 建议的单一新变体：soft-normalized phase

去除直流分量（DC，频谱零频位置，对应全图均值）后，对每张图每个颜色通道定义：

$$\tilde Z_{0,0}=0,\qquad
\tau=\max\left(10^{-6},\,0.1\,\operatorname{median}_{k\ne(0,0)}|\tilde Z_k|\right),$$

$$P_k^{soft}=\frac{\tilde Z_k}{\sqrt{|\tilde Z_k|^2+\tau^2}},\qquad
S_{soft}=\Re\mathcal F^{-1}(P^{soft}).$$

这里 $\tau$ 是本次冻结的数值正则阈值，**不是概率置信度、噪声估计或物理可靠性**。0.1 是待验证的设计值，不是论文定理或已找出的最佳值。首轮不展开多阈值搜索。

固定 $\tau>0$ 时：

$$Dp_{soft}(z)=\frac{I}{\sqrt{\|z\|^2+\tau^2}}-
\frac{zz^\top}{(\|z\|^2+\tau^2)^{3/2}}.$$

切向特征值为 $1/\sqrt{A^2+\tau^2}$，径向特征值为 $\tau^2/(A^2+\tau^2)^{3/2}$，均不超过 $1/\tau$。它消除了固定阈值下的低幅值奇点，但不是“所有扰动下一定更好”的证明。$\tau$ 本身依赖输入，后续 RMS 又依赖输入，完整组合映射不能直接继承上述固定 $\tau$ 的 Lipschitz 上界。

### 4.4 共同归一化与反例

为比较表示差异，新增支路的 Sobel、hard phase、soft phase 使用相同的中心化与 RMS 归一：

$$S_c=S-\operatorname{mean}_{H,W}(S),\qquad
\tilde S=\frac{S_c}{\max(\sqrt{\operatorname{mean}_{H,W}S_c^2},\epsilon_{rms})}.$$

建议固定 $\epsilon_{rms}=10^{-6}$、逐图逐通道计算，仅影响新增 adapter，不改父模型旧高频路径。零／常值图输出应为严格零或数值容差零。现有 Sobel 通过 $\sqrt{g_x^2+g_y^2+10^{-12}}$ 避免数值问题，常值图会返回 $10^{-6}$；若不中心化就 RMS 归一，会把这个数值地板放大成常量特征。

每图 RMS 归一的代价必须披露：它抹去了“整幅相位特征很弱”的幅值信号，但保留频率之间的相对衰减。不能再把归一化后强度解释为可靠性。若未来想用全局强度判别，应另提供归一前 RMS／幅值统计与独立效用校准；首轮不加入额外通道以免破坏等参数对照。

**反例一**：当 $A=\operatorname{median}A$、$\tau=0.1\operatorname{median}A$ 时，保留幅度为 $1/\sqrt{1.01}=0.9950$，几乎没有压低典型频率。该阈值主要处理极小幅值项。

**反例二**：对白噪声 $n$ 与 $0.001n$，若 $\tau$ 未触及下限，其自适应阈值同比缩放，$P^{soft}(0.001n)=P^{soft}(n)$；RMS 归一后两者仍相同。故该表示不具备“自动拒绝暗噪声”的数学性质。

因此正确可证伪假设是：**统一支路尺度后，对极小幅值频谱作平滑正则化，是否比单位相位和 Sobel 带来更好的重建／扰动表现？**不能预先声称“可靠相位恢复有效”。

## 5. D 的单次低预算实验，避免把表示、损失和训练扰动混在一起

只在 C 的预定继续条件未通过或被明确选作后备路线时启动。采用同一父权重、同一采样器、同一时间表、同一训练顺序、同一新增 adapter。

| 分支 | 新增输入 | 网络和预算 | 用途 |
|---|---|---|---|
| BASE_CONT_NEW | 无新增 adapter | 同步继续训练对照 | 排除继续训练效应 |
| D_SOBEL_NORM | 中心化／RMS 后 Sobel | `Conv3→32→base_width`，末层零初始化 | 匹配结构／容量控制 |
| D_PHASE_HARD_NORM | 去 DC、硬单位相位、共同归一 | 与 Sobel 完全相同 | 对照单位相位 |
| D_PHASE_SOFT_NORM | 上述 soft phase 与共同归一 | 与 Sobel 完全相同 | 唯一研究变体 |

主比较为 `SOFT − HARD`，并要求 `SOFT − SOBEL` 与 `SOFT − BASE_CONT_NEW` 不出现与目标相悖的退化。不能只找 SOFT 恰巧赢的某一个参照。

首轮不加相位损失、不增加 corruption training、不改变 legacy 高频注入、不换主干宽度、不改变感知损失权重。否则无法将结果归因于表示正则化。Phaseformer 可作为后续外部方法基线，但不必为了这个一次性筛选立即复刻其全模型。

建议先 1 个微调种子、固定 2000 步做数值／机制检查，再按主方案冻结的限额至 5000 步。2000 步不能因未达 `+0.10 dB` 直接叫方向无效；先检查新增末层参数更新、分支激活、梯度、损失曲线。若完全无激活或数值错误应停止修正。5000 步后仍未超过主要匹配控制的预设实用门槛，则保存负结果，不开展多阈值、多损失、多结构搜索。

只有开发集上的主要比较通过、跨场景方向一致、机制干预确实显示模型使用该支路时，才在预先冻结设置下完成 3 个**配对微调种子**确认。此条件并不保证论文新颖性；还需要明确相对 Phaseformer／既有相位正则化工作的差别。

## 6. 配对种子、统计和公平控制

三个微调种子可共享同一个固定父 checkpoint，研究的是“给定父模型后，新增方法对微调随机性的稳健性”；不得写成三个完整独立预训练种子。没有必要为首次确认重跑三次 400000 步。

每个种子内，方法与控制共享：数据次序、裁剪／翻转、扩散时间、训练噪声、评估噪声、总样本暴露、有效 batch、优化器重置策略、继承参数学习率、scheduler、检查点规则。新增模块自己的初始化和 dropout 使用独立随机流。

现有 `train.py:156` 与 `:157` 从全局 torch RNG 生成 t／noise；C 的 `PriorControl` 在 forward 中额外 `torch.rand`。因此“同一个整数 seed”和初始化 `fork_rng` 不保证 C 对照后续得到同样的训练噪声。新框架必须把数据、增强、t、noise、adapter dropout 分成独立生成器，或使用 `(run_seed,step,micro_batch,sample_id,role)` 键控随机数；不应靠重设一次全局 seed 声称配对成立。

固定评估 $x_T$ 的 3 个 seed 仅测采样随机性；它们不能代替训练随机性。图像 bootstrap 区间不能代替训练种子方差。建议先逐场景求每种子的配对差，再报告种子层均值／标准差和场景层配对 bootstrap；只有 3 个训练种子时不夸大总体显著性或种子分布估计精度。

检查点用固定步数或固定开发集选择规则，禁止每个分支分别挑测试最优。新一轮通过明确的训练／开发／确认保留集划分实现独立验证；既有测试只能作“历史 benchmark 再评估”，并披露它已影响方法设计。
